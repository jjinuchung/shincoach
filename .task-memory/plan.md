# 섀도잉 영어학습 PWA (shincoach) 계획서

> AI 외부 기억 장치 - 새 세션에서 이 파일을 먼저 읽으면 현재 상황을 즉시 파악할 수 있습니다.

## 목표
초등 4학년 아들이 사용할 **문장 단위 섀도잉 영어 학습 웹앱(PWA)** — 로컬 mp4 + 영/한 srt를 가져와 문장별 이동·반복·속도 조절·이중 자막·섀도잉 자동정지를 제공한다. PC Chrome에서 먼저 테스트하고 그대로 안드로이드 폰/태블릿에 설치한다.

## 배경
- 박코치 어학원 / 케이크(Cake) / Language Reactor 방식의 "장면(문장) 단위 따라 말하기" 훈련을 가정용으로 직접 만든다.
- 비상업, 가족용. 콘텐츠(애니 영상+자막)는 아버님이 직접 준비·검수한다.

## 접근 방식
- 프레임워크·빌드 없는 **순수 HTML/CSS/JS (ES 모듈)**. HTML5 `<video>`의 `playbackRate`(음정 유지)·`currentTime` 정밀 제어로 핵심 기능을 표준 API로 해결.
- 영상/자막은 파일 선택으로 한 번 가져오면 **IndexedDB에 저장** → 이후 파일 선택 없이, 오프라인으로 재생. 서버 불필요.
- 앱 껍데기(코드만)는 정적 호스팅(GitHub Pages 또는 Cloudflare Pages)에 올려 안드로이드에서 열고 "홈 화면에 추가". 영상은 기기에서 직접 가져오므로 서버에 올라가지 않음.
- 한글 자막은 영어 srt를 Claude 세션에서 직접 번역해 타임코드 동일한 ko.srt 생성 (API 키 없음).

## 작업 단계
1. [x] 프로젝트 골격: `index.html`, `css/`, `js/` 모듈, `manifest.webmanifest`, `sw.js`, 로컬 서버 실행 스크립트
2. [x] SRT 파서 + 영/한 자막 타임코드 매칭 (`js/srt.js`), 샘플 srt로 검증
3. [x] 콘텐츠 가져오기 & 라이브러리 (`js/db.js`, `js/library.js`) — mp4/en.srt/ko.srt를 IndexedDB 저장, 목록/삭제
4. [x] 플레이어 핵심 (`js/player.js`): 문장 이전/다음, 영어·한글 자막 표시/토글, 속도 0.5~1.25x
5. [x] 반복 & 섀도잉 모드: 현재 문장 N회 반복, 자동정지 → 따라말하기 → 다음
6. [x] 단어 하이라이트 + 전체 스크립트 목록(탭하면 이동) + 마지막 위치 이어보기
7. [ ] 아동용 UI 정리: 큰 터치 버튼, 폰 세로/태블릿 가로 반응형, 아이콘
8. [ ] PWA 검증: PC Chrome 설치·오프라인 → 안드로이드 폰 설치 테스트 (배포처 결정: GitHub Pages(Public) vs Cloudflare Pages(Private))
9. [ ] 자막 번역 워크플로: 영어 srt → 한글 srt (세션 내 직접 번역, 타임코드 유지) + 검증 스크립트
10. [ ] 실제 영상으로 전체 흐름 검증 + 엣지 케이스(자막 겹침, 빈 줄, 큰 파일)

## 기술 결정사항
- 순수 HTML/CSS/JS, ES 모듈, 외부 라이브러리 없음 (오프라인 보장)
- 저장: IndexedDB (영상 Blob, 자막 텍스트, 진행 상태)
- PWA: `manifest.webmanifest` + `sw.js` (앱 셸 캐시)
- 단어 하이라이트: srt 문장 시간을 글자 수 비례로 단어에 배분(근사)
- 섀도잉: 문장 재생 → 정지 → 문장 길이×1.5초 대기 → 자동 다음 (탭으로 즉시 넘김)
- 로컬 테스트: `python -m http.server` (서비스워커는 file://에서 동작 안 함)

## 제약 조건
- 안드로이드 Chrome에서 동작해야 함 (File System Access API 미지원 → `<input type="file">` 사용)
- 초등학생 UI: 큰 버튼, 글자 크게, 조작 단순
- 커밋은 사용자가 결정 (자동 커밋 금지), Conventional Commits
- 영상/자막 파일은 저장소에 커밋하지 않음 (.gitignore)

## 예상 위험
- IndexedDB 용량: 영상 여러 편이면 수 GB → 브라우저 quota 확인 (`navigator.storage.estimate`), persist 요청
- 안드로이드 Chrome에서 `playbackRate` 0.5x 음질 저하 가능 → 0.7x 정도를 기본 느림 속도로
- srt 인코딩(UTF-8 BOM, CP949) 문제 → 파서에서 BOM 제거, 인코딩 안내
- 영/한 srt 타임코드 불일치 시 매칭 실패 → 번역 워크플로에서 타임코드 그대로 유지하는 것을 원칙으로

# 👨‍👩‍👦 아빠가 고쳐준 글 (배포로 전달)

태블릿에 손으로 옮겨 적지 않아도 되게, **교정문을 앱과 함께 배포**한다.

## 어떻게 도는가

1. 진우가 앱에서 에세이를 씀 → 📊 학습 기록에 `[1] 고쳐 주세요` 배지와 함께 쌓임
2. 아버님이 그 화면을 **사진으로 찍어** Claude에게 보여줌
3. Claude가 이 파일(`coach/fixes.json`)에 교정문을 적고 **커밋·배포**
4. 진우가 앱을 열면 새 버전을 받으면서 교정문이 **자동으로 붙는다**
   → "👨‍👩‍👦 아빠가 고쳐준 글" 화면에서 읽기

## 파일 형식

```json
[
  {
    "written": "I want to play with my brother at a park",
    "fixed": "I want to play with my brother at the park."
  }
]
```

- `written` — **아이가 쓴 문장 그대로** (사진에서 옮겨 적음). 이게 짝을 찾는 열쇠다.
  대소문자·구두점은 무시하고 비교하므로 완벽히 같지 않아도 된다.
  그래도 못 찾으면 앞 4단어로 한 번 더 찾는다.
- `fixed` — 고친 문장. 아이가 이걸 소리 내어 읽는다.
- `origin` — (선택) 배운 문장. `written` 으로 못 찾을 때 마지막으로 이걸로 찾는다.

## 규칙

- 이미 고쳐 준 글(`coachFix` 가 있는 것)은 건드리지 않는다 → 같은 파일이 여러 번 배포돼도 안전하다
- 짝을 못 찾으면 조용히 넘어간다 (다른 기기·지워진 기록일 수 있다)
- 다 붙고 나면 이 파일을 `[]` 로 비워도 되고, 그냥 둬도 된다 (중복 적용 안 됨)
- 진우가 읽고 나면 다시 뜨지 않는다 (`readAt` 기록)

등식과 방정식

등호(=)를 써서 두 수나 식이 같음을 나타낸 식을 등식이라고 해요. 등호의 왼쪽은 좌변, 오른쪽은 우변, 둘을 함께 양변이라고 해요. x의 값에 따라 참이 되기도 하고 거짓이 되기도 하는 등식을 x에 대한 방정식, 이때 x를 미지수라고 해요. 방정식을 참이 되게 하는 x의 값이 그 방정식의 해(또는 근)예요.

📘 배움 5장 · 진우가 읽는 것 · 확인 질문에 답해야 다음 장

  1. 1
    1장Q1-1

    수학에서 =는 "양쪽이 같아요"라는 기호예요. 이름은 등호예요.

    3 + 4 = 7

    이렇게 등호를 써서 두 수나 식이 같음을 나타낸 식을 등식이라고 해요. 3 + 4 = 8도 등식이에요 — 양변의 값이 달라서 거짓인 등식이에요. 문자가 있어도 등호가 있으면 등식이에요 — x + 4 = 9도 등식이에요.

    등호가 없으면 등식이 아니에요.
    · x + 4 — 식일 뿐이에요
    · x + 4 < 9 — <는 크기를 비교하는 기호예요
    · 6 × 2 − 1 — 계산하는 식이에요

    확인 질문Q1-1✓

    다음 중 등식은 어느 것일까요?

    1. ✔4x + 1 = 13
    2. 4x + 1
    3. 4x + 1 < 13

    틀리면등호(=)가 있는 것만 등식이에요. 4x + 1은 식이고, <는 크기를 비교하는 기호예요.

  2. 2
    2장Q1-2

    등식에서 등호의 왼쪽을 좌변, 오른쪽을 우변이라고 해요. 좌변과 우변을 함께 양변이라고 해요.

    2x + 3 = 11

    좌변은 2x + 3, 우변은 11이에요.

    x 자리에 수를 넣어 양변을 비교해 봐요. 2x는 2 × x라서 x = 4를 넣으면 좌변은 2 × 4 + 3 = 11 — 우변과 같아요. x = 5를 넣으면 좌변은 2 × 5 + 3 = 13 — 우변과 달라요.

    확인 질문Q1-2✓

    등식 3x + 5 = 17의 좌변에 x = 4를 넣으면 얼마일까요?

    1. ✔17
    2. 39
    3. 12

    틀리면3x는 3 × x예요. 3 × 4 + 5 = 17 — 우변과 같아요. 3과 4를 나란히 붙여 34로 읽거나, 3 + 4로 더하면 안 돼요.

  3. 3
    3장Q1-3

    등식 x + 4 = 9의 x 자리에 여러 수를 넣어 봐요.

    · x에 5를 넣으면 5 + 4 = 9 — 참
    · x에 3을 넣으면 3 + 4 = 7 — 우변 9와 달라서 거짓

    x의 값에 따라 참이 되기도 하고 거짓이 되기도 하는 등식을 x에 대한 방정식이라고 해요. 이때 값을 모르는 x를 미지수라고 해요.

    확인 질문Q1-3✓

    다음 중 x = 2일 때 참이 되는 등식은 어느 것일까요?

    1. ✔5x + 3 = 13
    2. 5x + 3 = 55
    3. 5x + 3 = 10

    틀리면x = 2를 넣으면 5 × 2 + 3 = 13이에요. 5x는 5 × x라서 52도 아니고, 5 + 2도 아니에요.

  4. 4
    4장Q1-4

    방정식을 참이 되게 하는 x의 값을 그 방정식의 해라고 해요. 근이라고도 해요.

    x + 4 = 9의 해는 x = 5예요.

    해를 찾는 한 가지 방법은 x에 수를 차례로 넣어 보는 거예요. 방정식 3x − 1 = 8에 1, 2, 3을 넣어 보면

    · 3 × 1 − 1 = 2
    · 3 × 2 − 1 = 5
    · 3 × 3 − 1 = 8 — 우변과 같아요!

    그래서 3x − 1 = 8의 해는 x = 3이에요.

    확인 질문Q1-4✓

    x의 값이 1, 2, 3, 4, 5일 때, 방정식 2x + 5 = 13의 해는 얼마일까요?

    1. ✔4
    2. 13
    3. 6

    틀리면x에 4를 넣으면 2 × 4 + 5 = 13 — 우변과 같아요. 13은 우변의 수일 뿐이고, 2x는 2 × x라서 2와 x를 더하지 않아요.

  5. 5
    5장Q1-5

    해가 맞는지는 넣어서 확인해요. 방정식 4x + 1 = 13에 x = 3을 넣으면 4 × 3 + 1 = 13 — 양변이 같아요. 그래서 4x + 1 = 13의 해는 x = 3이에요.

    조심할 것 하나 — 4x는 4 × x예요. x = 3을 넣을 때 4와 3을 나란히 붙여 43으로 읽으면 안 돼요. 4 + 3으로 더해도 안 돼요.

    확인 질문Q1-5✓

    다음 중 해가 x = 3인 방정식은 어느 것일까요?

    1. ✔2x + 7 = 13
    2. 2x + 7 = 30
    3. 2x + 7 = 12

    틀리면x = 3을 넣어 봐요. 2 × 3 + 7 = 13이라서 2x + 7 = 13의 해가 x = 3이에요. 2와 3을 붙이거나(23) 더하면(2 + 3) 안 돼요.

항등식

x에 어떤 값을 넣어도 늘 참인 등식을 x에 대한 항등식이라고 해요. 2x + 3x = 5x처럼 좌변을 간단히 하면 우변과 똑같아지는 등식이에요. 방정식은 어떤 값을 넣을 때만 참이지만, 항등식은 모든 값에서 참이에요.

📘 배움 4장 · 진우가 읽는 것 · 확인 질문에 답해야 다음 장

  1. 1
    1장Q2-1

    등식 2x + 3x = 5x의 x 자리에 아무 수나 넣어 봐요.

    · x에 1을 넣으면 좌변 2 × 1 + 3 × 1 = 5, 우변 5 × 1 = 5
    · x에 2를 넣으면 좌변 2 × 2 + 3 × 2 = 10, 우변 5 × 2 = 10
    · x에 10을 넣으면 좌변 2 × 10 + 3 × 10 = 50, 우변 5 × 10 = 50

    어떤 수를 넣어도 늘 참이에요! 이렇게 x에 어떤 값을 넣어도 참이 되는 등식을 x에 대한 항등식이라고 해요. 그래서 2x + 3x = 5x는 x에 대한 항등식이에요.

    방정식 x + 4 = 9는 x에 5를 넣을 때만 참이었지요. 항등식은 모든 값에서 참이에요.

    확인 질문Q2-1✓

    다음 중 x에 대한 항등식은 어느 것일까요?

    1. ✔4x + 2x = 6x
    2. 4x + 2 = 6x
    3. 3x = 12

    틀리면4x + 2x는 간단히 하면 6x라서 어떤 값을 넣어도 참이에요. 4x + 2 = 6x는 x에 1을 넣을 때만 참이고, 3x = 12는 x에 4를 넣을 때만 참인 방정식이에요.

  2. 2
    2장Q2-2

    수를 끝없이 넣어 볼 수는 없어요. 그래서 항등식인지는 양변을 간단히 해서 봐요. 간단히 한 좌변과 우변이 똑같으면 항등식이에요.

    3(x + 2) = 3x + 6

    좌변의 괄호를 풀면 3x + 6 — 우변과 똑같아요. 그래서 3(x + 2) = 3x + 6은 x에 대한 항등식이에요.

    괄호를 풀 때는 괄호 안 모든 항에 곱해요(분배법칙). 3 × x와 3 × 2를 둘 다 해야 해요.

    확인 질문Q2-2✓

    등식 4(x + 3) = 4x + □가 x에 대한 항등식이 되려면 □ 안에 알맞은 수는 얼마일까요?

    1. ✔12
    2. 3
    3. 7

    틀리면좌변의 괄호를 풀면 4x + 12예요. 괄호 안 3에도 4를 곱해야 해요 — 4와 3을 더하지 않아요.

  3. 3
    3장Q2-3

    한 값에서 참이라고 항등식은 아니에요.

    2x + 1 = x + 4

    x에 3을 넣으면 좌변 2 × 3 + 1 = 7, 우변 3 + 4 = 7 — 참이에요. 그런데 x에 0을 넣으면 좌변은 1, 우변은 4 — 거짓이에요. 그래서 2x + 1 = x + 4는 항등식이 아니라 방정식이에요.

    항등식인지 알아보려면 넣어 보기보다 간단히 해서 양변이 똑같은지 봐요. 2x + 1과 x + 4는 간단히 해도 달라요.

    확인 질문Q2-3✓

    등식 3x + 5x − 2 = □x − 2가 x에 대한 항등식이 되려면 □ 안에 알맞은 수는 얼마일까요?

    1. ✔8
    2. 15
    3. 3

    틀리면좌변을 간단히 하면 3x + 5x − 2 = 8x − 2예요. 동류항은 계수끼리 더해요 — 곱하지 않고, 5x도 빠뜨리지 않아요.

  4. 4
    4장Q2-4

    방정식과 항등식을 정리해 봐요.

    · 방정식 — 어떤 값을 넣을 때만 참 (2x + 1 = 7은 x에 3을 넣을 때만 참)
    · 항등식 — 어떤 값을 넣어도 참 (x + x = 2x)

    2x와 3은 동류항이 아니라서 2x + 3을 5x로 합칠 수 없어요. 그래서 2x + 3 = 5x는 항등식이 아니에요. x에 1을 넣으면 참이지만, 다른 수를 넣으면 거짓이에요.

    확인 질문Q2-4✓

    등식 2x + 4 = 6x는 x = 1일 때 참이에요.

    이 등식은 항등식일까요?

    1. ✔아니요, x = 2일 때는 거짓이라서 방정식이에요
    2. 네, 참이 되는 값이 있으니까 항등식이에요
    3. 네, 2x + 4를 간단히 하면 6x예요

    틀리면항등식은 모든 값에서 참이어야 해요. x = 2를 넣으면 좌변 8, 우변 12라서 거짓이에요. 2x와 4는 동류항이 아니라서 6x로 합칠 수 없어요.

등식의 성질

등식의 양변에 같은 수를 더하거나 빼거나 곱해도 등식은 그대로 성립해요. 0이 아닌 같은 수로 나누어도 성립해요. 이것을 등식의 성질이라고 해요. 수평인 저울 양쪽에 같은 무게를 올리거나 내려도 수평인 것과 같아요. 0으로는 나눌 수 없어요.

    1장Q3-1

    수평인 저울은 등식과 닮았어요. 양쪽 무게가 같으니까요.

    왼쪽 접시에는 x 상자 1개와 1 추 3개, 오른쪽 접시에는 1 추 7개가 있어요. 등식으로 쓰면 x + 3 = 7이에요.

    양쪽에서 1 추를 3개씩 똑같이 덜어 내도 저울은 수평이에요.

    이제 왼쪽에는 x 상자만, 오른쪽에는 1 추 4개가 남아요 — x 상자 하나의 무게는 1 추 4개와 같아요.

    1. ✔6
    2. 10
    3. 14

    틀리면양쪽에서 똑같이 4개씩 덜어 내요. 오른쪽은 10 − 4 = 6개 — 저울은 그대로 수평이에요. 한쪽에서만 덜어 내면 기울고, 덜어 내는 것은 더하기가 아니라 빼기예요.

  2. 2
    2장Q3-2

    저울로 알아낸 것을 등식에도 그대로 쓸 수 있어요. 저울 양쪽처럼 서로 같은 두 양을 a와 b라고 하면, a = b일 때

    · 양변에 같은 수를 더해도 — a + 2 = b + 2
    · 양변에서 같은 수를 빼도 — a − 2 = b − 2
    · 양변에 같은 수를 곱해도 — a × 2 = b × 2
    · 양변을 0이 아닌 같은 수로 나누어도 — a ÷ 2 = b ÷ 2

    등식은 그대로 성립해요. 이것을 등식의 성질이라고 해요. 핵심은 "양변에 똑같이"예요.

    2. a − 5 = b
    3. a − 5 = b + 5

    틀리면양변에서 똑같이 5를 빼야 등식이에요. 한쪽에서만 빼거나, 한쪽은 빼고 한쪽은 더하면 양변이 같다고 할 수 없어요.

    x + 1 = 4
    → 2x + 2 = 8

    2x + 2 = 8
    → x + 1 = 4

    양변에 같은 수를 곱해도, 0이 아닌 같은 수로 나누어도 등식은 그대로예요.

이항과 일차방정식

등식의 성질을 써서 한 변의 항을 부호를 바꾸어 다른 변으로 옮기는 것을 이항이라고 해요. x + 3 = 7에서 3을 이항하면 x = 7 − 3이에요. 이항해서 정리했을 때 (x에 대한 일차식) = 0 꼴이 되는 방정식을 x에 대한 일차방정식이라고 해요.

📘 배움 5장 · 진우가 읽는 것 · 확인 질문에 답해야 다음 장

  1. 1
    1장Q5-1

    x + 3 = 7을 풀 때 양변에서 3을 뺐어요.

    x + 3 = 7
    → x = 7 − 3

    잘 보면 좌변에 있던 +3이 우변으로 건너가 −3이 되었어요. 이렇게 등식의 성질을 써서 한 변의 항을 부호를 바꾸어 다른 변으로 옮기는 것을 이항이라고 해요.

    · +는 건너가면 −
    · −는 건너가면 +

    확인 질문Q5-1✓

    방정식 2x + 5 = 13에서 5를 이항하면 어느 것일까요?

    1. ✔2x = 13 − 5
    2. 2x = 13 + 5
    3. 2x = 5 − 13
    4. x = 13 − 5 − 2

    틀리면+5를 우변으로 옮기면 −5가 돼요. 우변 13에서 5를 빼는 순서예요. 2는 x에 곱해진 수라서 이항하지 않아요 — 나중에 양변을 2로 나눠요.

  2. 2
    2장Q5-2

    빼진 항을 옮기면 더하기가 돼요.

    3x − 4 = 8
    → 3x = 8 + 4
    → 3x = 12
    → x = 4

    x가 있는 항도 똑같이 이항할 수 있어요. 우변의 2x를 좌변으로 옮기면 −2x가 돼요.

    5x = 2x + 9
    → 5x − 2x = 9
    → 3x = 9
    → x = 3

    어느 항이든 옮기면 부호가 바뀌어요.

    확인 질문Q5-2✓

    방정식 4x − 3 = 9에서 −3을 이항하면 어느 것일까요?

    2. 4x = 9 − 3

    틀리면−3을 우변으로 옮기면 +3이 돼요 — 4x = 9 + 3 → 4x = 12 → x = 3. 4는 곱해진 수라서 이항하지 않아요.

    이항으로 방정식을 푸는 순서예요.

    ① x가 있는 항은 좌변, 수만 있는 항은 우변으로 이항해요.
    ② 양변을 정리해서 (수)x = (수) 꼴로 만들어요.
    ③ 양변을 x의 계수로 나눠요.

    15 − 2x = 7
    → −2x = 7 − 15
    → −2x = −8
    → x = 4

    마지막에 −2로 나누면 (−8) ÷ (−2) = 4 — 음수를 음수로 나누면 양수예요.

    3. −4

    (x에 대한 일차식) = 0

    꼴이 되는 방정식을 x에 대한 일차방정식이라고 해요.

    · 2x + 1 = 7 → 2x − 6 = 0 — 일차방정식
    · x² + 1 = 5 — x²이 있어서 일차방정식이 아니에요
    · 3x + 1 = 3x − 2 → 3 = 0 — x가 없어져서 일차방정식이 아니에요
    · 2x − 6 — 등호가 없어서 방정식이 아니에요

    확인 질문Q5-4✓

    3. 2x + 4 = 2x − 1
    4. 5x − 1

    틀리면5x − 1 = 9는 이항하면 5x − 10 = 0이라서 일차방정식이에요. x² − 1 = 8은 x²이 있고, 2x + 4 = 2x − 1은 x가 없어지고, 5x − 1은 등호가 없어요.

    아래 방정식은 x²이 보이지만 양변에 똑같이 있어요. 이항하면 x² − x²이 없어져서 일차방정식이 돼요.

    x² + 2x = x² + 6
    → 2x − 6 = 0

    거꾸로 x가 있어도 이항해서 x가 없어지면 일차방정식이 아니에요.

양변에 x가 있는 방정식

x가 있는 항은 좌변으로, 수만 있는 항은 우변으로 이항해서 (수)x = (수) 꼴로 정리한 다음 양변을 x의 계수로 나눠요. 5x − 3 = 2x + 9 → 5x − 2x = 9 + 3 → 3x = 12 → x = 4. 구한 해를 처음 방정식에 넣어 맞는지 확인해요.

괄호가 있는 방정식

괄호가 있으면 분배법칙으로 괄호를 먼저 풀어요. 2(x − 3) = x + 4 → 2x − 6 = x + 4 → 2x − x = 4 + 6 → x = 10. 괄호 앞이 −이면 괄호 안 모든 항의 부호를 바꿔요.

    2(x − 3) = x + 4
    → 2x − 6 = x + 4
    → 2x − x = 4 + 6
    → x = 10

계수가 분수·소수인 방정식

계수가 소수이면 양변에 10을 곱하고, 분수이면 양변에 분모의 최소공배수를 곱해서 계수를 정수로 고친 다음 풀어요. 이때 수만 있는 항까지 모든 항에 곱해야 해요. 0.3x + 0.2 = 1.1 → 양변에 10을 곱하면 3x + 2 = 11 → x = 3.

    1장Q8-1

    계수가 소수이면 계산이 번거로워요. 양변에 10을 곱해서 소수를 자연수로 바꿔요.

    0.3x + 0.2 = 1.1
    → 3x + 2 = 11
    → 3x = 9
    → x = 3

    0.3x × 10 = 3x, 0.2 × 10 = 2, 1.1 × 10 = 11 — 모든 항에 10을 곱했어요. 소수 둘째 자리까지 있으면 100을 곱해요.

    → x = 6

⭐ 일차방정식의 활용

활용 문제는 ① 구하려는 것을 x로 놓고 ② 문제의 뜻에 맞게 방정식을 세우고 ③ 풀고 ④ 구한 값이 문제에 맞는지 확인해요 — 개수·사람 수는 자연수인지, 묻는 것이 x 그대로인지도 봐요.

📘 배움 5장 · 진우가 읽는 것 · 확인 질문에 답해야 다음 장

  1. 1
    1장Q9-1

    문장으로 된 문제는 네 단계로 풀어요.

    ① 구하려는 것을 x로 놓아요
    ② 문제의 뜻에 맞게 방정식을 세워요
    ③ 방정식을 풀어요
    ④ 구한 값이 문제에 맞는지 확인해요

    어떤 수의 3배에서 4를 뺐더니 11이 되었어요. 어떤 수를 x라고 하면

    3x − 4 = 11
    → 3x = 15
    → x = 5

    확인: 3 × 5 − 4 = 11 ✔ 어떤 수는 5예요.

    확인 질문Q9-1✓

    어떤 수의 4배에서 2를 뺐더니 18이 되었어요.

    어떤 수는 얼마일까요?

    1. ✔5
    2. 20
    3. 4

    틀리면어떤 수를 x라고 하면 4x − 2 = 18 → 4x = 20 → x = 5. 확인: 4 × 5 − 2 = 18 ✔ −2를 이항하면 +2이고, 마지막에 4로 나눠요.

  2. 2
    2장Q9-2

    연속하는 자연수는 1씩 커져요. 가장 작은 수를 x라고 하면 세 수는 x, x + 1, x + 2예요.

    연속하는 세 자연수를 모두 더했더니 33이 되었어요.

    x + (x + 1) + (x + 2) = 33
    → 3x + 3 = 33
    → 3x = 30
    → x = 10

    세 수는 10, 11, 12예요. 묻는 것이 가장 작은 수인지, 가운데 수인지 꼭 다시 봐요.

    확인 질문Q9-2✓

    연속하는 세 자연수를 모두 더했더니 48이 되었어요.

    세 수 중 가장 작은 수는 얼마일까요?

    1. ✔15
    2. 16
    3. 45

    틀리면가장 작은 수를 x라고 하면 x + (x + 1) + (x + 2) = 48 → 3x + 3 = 48 → 3x = 45 → x = 15. 16은 가운데 수이고, 3x = 45에서 3으로 나눠야 해요.

    3장Q9-3

    나이 문제에서는 시간이 지나면 모두 똑같이 나이를 먹어요.

    지금 진우는 10살, 아빠는 38살이에요. 아빠 나이가 진우의 나이의 3배가 되는 것은 몇 년 후일까요?

    38 + x = 3(10 + x)
    → 38 + x = 30 + 3x
    → x − 3x = 30 − 38
    → −2x = −8
    → x = 4

    4년 후 진우는 14살, 아빠는 42살 — 정말 3배예요.

    → x = 3
